# Main-text Potts proof map

This document maps Sections 2 and 3 of `main.tex`, including the imported files `sections/strict-ci-tools.tex` and `sections/strict-vigoda-ci.tex`, to the Lean proofs. It covers the model, concrete Vigoda coupling, complex-analytic transfer, both endpoints, and the Potts main theorem. It does not certify every Appendix extension. Holant is documented separately in [README.md](README.md) and [HOLANT_AUDIT.md](HOLANT_AUDIT.md). Lean paths below are relative to the repository root; paper labels and line numbers refer to the source snapshot recorded in `source-manifest.json`.

The verification environment is Lean 4.33.1 and mathlib v4.33.1. The full publishing-checkout run of `./scripts/check.sh` on 2026-09-09 passed **3665 build jobs** and the transitive axiom audit of **4014 project declarations**. The aggregate imports **197 project Lean source files**, including the root `CI2ZF.lean`; `AxiomAudit.lean` is run separately. These totals include the completed Holant modules. All completed entries below have compiled. The audit permits only `propext`, `Classical.choice`, and `Quot.sound`; external mathematical inputs appear as explicit theorem parameters. A code scan of the imported source closure, with comments and strings removed, found no `sorry`, `admit`, custom `axiom`, `native_decide`, or `unsafe` declarations.

`UniformPottsZeroFree` places `∃ ε > 0` before the quantifiers over finite vertex types, graphs, and pinnings. It gives nonvanishing of the normalized partition function, identifies the only possible zeros of the full partition function in this neighborhood as the forced zero at `z = 0`, and gives its exact multiplicity. Thus the theorem chooses a radius for the entire graph family. The earlier fixed-instance result in `FixedGraph.lean` is an auxiliary theorem with a different quantifier order.

## External input and scope boundaries

- **Strict-regime CI is proved within the library.** `hardStep_W_drift_le` in `HardCouplingCost.lean` connects actual graph components and probability allocations. `PottsCITheorem` applies common-coin averaging, path coupling, and stationary comparison. The final strict theorem does not ask for a `ConditionalHardCouplingEstimate`.
- **Hard-coloring CI at equality remains an explicit literature input.** The paper cites CFFGZZ2024, Theorem 20 and Proposition 22. Lean takes the required statement as a `CriticalHardColouringInput` parameter, or publicly as `ExternalCriticalHardColouringTheorem` on original graphs. The original-graph premise is proved to imply the internal boundary-count version. The external paper's proof has not itself been formalized here, and no corresponding custom axiom is introduced. Positive-temperature CI at equality is proved by the concrete Vigoda chain. See [EXTERNAL_INPUTS.md](EXTERNAL_INPUTS.md).
- **General graph-class transfer is a conditional theorem in the paper.** `GraphClassTransferInputs` and `TransferCouplingInputs` express its CI hypotheses. The transfer, the choice of a uniform radius, and the concrete model connections are proved in Lean. Closure of `AmbientRealization` under restriction keeps recursive instances within appropriate induced subgraphs and pinnings.
- **Arbitrary pinning includes improper pinning.** The normalized polynomial omits pinned-only edges and imposes no properness condition on the original pinning. The full polynomial's forced factor and exact zero multiplicity are proved separately. Conflicts created by adding a root pin are handled in the actual recursion.
- **Empty cases and endpoints are included.** With no free vertices the normalized partition function is 1. Wasserstein distance on an empty remaining vertex space is zero, and the empty hard chain holds. Empty exteriors, disconnected components, and single-vertex recursions are not excluded by hidden nonemptiness assumptions. The hard endpoint uses feasibility and finite-law limits; `x = 1` uses identities for the uniform law.
- **The concrete profile is distinguished from the general tools.** The implemented profile is `p_1=1, p_2=13/42, p_3=1/6, p_4=2/21, p_5=1/21, p_6=1/84`, and `p_s=0` for `s≥7`. All generic profile-ρ variants, ancillary irreducibility results, and unused variants are outside this map's completion claim. This implementation choice is not an unproved input to the completed main theorem.
- **Unimported Appendix sources have separate status.** The publishing checkout preserves 75 existing files under `CI2ZF/Appendix/`. They are outside the 197-file aggregate closure and its audit. Their presence does not extend the scope certified by the default check. In particular, the leaf model's girth-preservation lemma does not establish the separate high-girth zero-free extensions.

## Verification and suggested reading order

Start with the statements in `PottsExternalTheorem.lean` and `PottsMainTheorem.lean`. The coupling branch runs through `TransferCouplingInputs → PottsCITheorem → HardCouplingCost`; the analytic branch runs through `UniformZeroFreePackaging → UniformInduction → Positive/HardUniformTransfer`. For general classes, read `GraphClassInputs → GraphClassCoupling → FamilyUniformTransfer → GraphClassPottsTransfer`. The principal concrete-model bridges are in `PottsModel`, `RootChildren`, `RootGibbsSemantics`, `GenericGibbsRelabel`, and `OptionBFSMarginals`.

From the repository root, `./scripts/check.sh` builds the complete aggregate and runs its axiom audit. Individual entry points can be checked with `./scripts/lake.sh build CI2ZF.PottsMainTheorem`, `CI2ZF.GraphClassPottsTransfer`, or `CI2ZF.PottsExternalTheorem`. For individual declarations, use `#print axioms` and inspect the explicit mathematical hypotheses as well: a theorem depending only on the three allowed logical axioms can still have explicit mathematical premises.
